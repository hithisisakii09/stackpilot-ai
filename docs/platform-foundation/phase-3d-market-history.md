# Historical market analysis and seasonality readiness

`prepareMarketHistorySelection({subjectIds,metric,unit,region,fromMonth,throughMonth})` validates up to five subjects, one existing market metric, explicit units/region and one through thirty-six completed UTC calendar months. Month names use YYYY-MM. A month begins at its first millisecond and ends one millisecond before the next month. A validated reference clock is optional for deterministic selection tests.

`analyzeMarketHistory({selection,observations,links,staleIds})` calculates method calendar-month-change-v1. It reuses existing immutable observation normalization, revision checks and reconciliation graph/source annotations. Latest series revisions supply candidate values. Original history remains digest-bound. A period reassigned by revision, missing/foreign ancestor, conflicting category, partial/overlapping period, incompatible unit, incomplete provenance/value, stale binding or unresolved correction produces UNKNOWN for the affected monthly cell.

Identical observations are deduplicated. Distinct agreeing observations retain their IDs and supply one declared value. Monthly observationIds preserve overlapping history, while activeObservationIds identify the current revisions used by calculations. Change-result observationIds refer to those active inputs. Contradictory values remain UNKNOWN. Counts and index values are never summed or averaged across declarations. Missing expected months retain explicit null cells. Coverage distinguishes months with any observation from comparable months and lists months with no observations.

Adjacent comparisons and matching-month prior-year comparisons return absolute change, relative percentage change, units, contributing IDs and reasons. Absolute percent-unit changes use percentage-points, while index values use index-points. Relative change is `(current-baseline)/baseline*100`. Results round to six decimal places. A zero baseline or nonfinite relative result returns null relative percentage with an explicit reason. An unavailable endpoint retains null changes. Comparisons keep explicit month identities and preserve gaps.

Seasonality readiness reports the longest run of consecutive comparable months. A run of at least twenty-four months provides sufficient-history coverage and review-required status. Leading/trailing gaps stay visible in coverage. A gap inside a candidate run breaks that run. Complete cycles count twelve-month runs. Twenty-four months is the engineering coverage threshold selected for this slice. Evidence confidence remains UNKNOWN and review state remains unreviewed. Independent method and source review remain outstanding.

`openReconciliationStore(config).scope(organizationId).historical(selection)` is the additive persistent entry. It reuses the existing disposable market database gate, migration target7, restricted role, tenant isolation and shared one-statement snapshot reader. The query reads complete selected subject/metric/region history and related links, capped at one hundred records/links, including revisions outside displayed months. Overflow fails explicitly. This preserves supersession visibility across window boundaries. Analysis performs no domain/audit/outbox writes.

Subject digests bind method, selection and all contributing history/link annotations. The aggregate digest binds selected subjects and their digests. Existing Phase3A opportunity and Phase3C reconciled-analysis APIs retain their behavior. Fixtures use synthetic observations. Owner provisioning, authenticated operational use and independently reviewed research remain separate gates.
