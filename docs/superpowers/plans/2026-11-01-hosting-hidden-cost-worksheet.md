# Phase 3.7 — Hosting hidden-cost worksheet (2026-11-01)

**Purpose:** Deliver an original buyer utility from `docs/growth/2026-10-31-zero-budget-organic-acquisition-pipeline.md` rather than repeat UAT paperwork. This is a private, offline calculation for *user-entered* hosting quotes, not vendor pricing verification, commercial promotion or a production change.

## Scope / architecture (gstack Think and Plan)
- New pure `src/lib/hosting-hidden-costs.mjs`. `calculateHostingHiddenCosts(input)` accepts **exact fields** `currency` (INR/USD/EUR/GBP), `months` (integer 1–60), `overlapMonths` (integer 0..months), `baseMonthly`, `backupMonthly`, `bandwidthMonthly`, `supportMonthly`, `otherMonthly`, `oldHostingMonthly`, `migrationOnce`, `cancellationOnce` (currency decimal strings; 0–1,000,000.00, at most two decimal places). Reject unknown fields, non-finite/invalid amounts, negative/exponential/locale-formatted numbers, mismatched currency, unsafe integers. Base monthly must be positive? **No**: free-tier quoted base 0 is legitimate; labels clearly estimates.
- All arithmetic in **integer minor currency units** using `formatMinorUnits` (existing cost comparison module): new-host monthly recurring = sum five monthly fields; headline-only baseline = base × horizon; additional costs = (extras four monthly fields × horizon) + old-host overlap cost + two one-time fees; total = baseline + additional. One-time fees not multiplied by months. Old hosting overlap only multiplied by actual user-specified overlap duration; never treat as entire horizon. No inflation, renewal/plan upgrades, sales tax or FX implicitly assumed. All totals must be safe integer.
- The result always includes `dataSource:'user-entered-only'`, `independentlyVerified:false`, `providerQuoteVerified:false` and `purchaseAuthorized:false`. `formatHostingHiddenCostReport(result)` and `formatHostingHiddenCostCsv(result)` recompute every derived property from immutable input values and reject fabricated approvals, stale reports and unknown fields; CSV formula injection impossible because only fixed labels, enums and numbers are serialized.
- New static, noindex, local-browser `src/pages/tools/hosting-hidden-costs/index.astro`; 10 visible fields plus currency/horizon/overlap, clear formula/assumptions, report, offline CSV and copy, strict disable-on-change/reset/invalid, accessible desktop/mobile, no uploads, telemetry or network calls. Mention existing hosting-layer Netlify Web Analytics may record visits but not inputs. Add homepage link and meaningful link from hosting migration guide. Browser QA tests real CSV, incremental recomputation, no form transmission, stale invalidation, axe, 390px viewport.
- New unit tests `tests/hosting-hidden-costs.test.mjs` and static UI tests `tests/hosting-hidden-costs-page.test.mjs`. Extend `scripts/browser-acceptance.mjs` desktop/mobile and private `src/lib/preview-uat-packet.mjs` source-generated human test cases for this new tool.
- No dependencies, vendor assertions, affiliate links, external rates/quotes, or public publishing.
