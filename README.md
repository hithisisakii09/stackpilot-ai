# StackPilot AI

Independent SaaS discovery MVP for small agencies, built with Astro.

## Run

```bash
npm install
npm run check:data
npm run dev
```

Build: `npm run build`. The static output is in `dist/`.

## Current limitations

- No affiliate links are active; all vendor URLs are official websites.
- The quiz is a basic category matcher; team size and budget inputs are collected locally but are not yet used for ranking.
- Product prices and claims are not independently verified.
- No analytics, user accounts, tracking cookies, payments, or autonomous publishing.
- Before commercial launch, verify hosting terms, affiliate eligibility, privacy requirements and disclosures.
